# Brief: GGML_CUDA_MMVQ_Q8_WIDE — faster 5-column Q8_0 MMVQ on NVIDIA (bit-exact, default off)

## Goal
Speed up the Q8_0 matrices in the speculative verify (5 columns: MTP n=4 + 1) of Qwen3.8-27B UD-Q6_K_M on an RTX 3090
(sm_86, 82 SMs, 936 GB/s). Q8_0 is 25% of the weight bytes (5.9 GB, incl. the 1.35 GB LM head). nsys (2026-10-20,
197 verify steps, kernel durations):

| launch (grid × 2 rows, regs) | what | mean µs | GB/s |
|---|---|---|---|
| 2560 blocks, 88 regs, fused (bias/residual) | Q8_0 5120 rows × K=6144 (ssm_out / attn_output), 33.4 MB | 69.5 | **481** |
| 3072 blocks, 80 regs | Q8_0 6144 rows × K=5120, 33.4 MB | 46.5 | 718 |
| 8704 blocks, 80 regs | Q8_0 17408×5120 | 116.3 | 800 |
| 17408 blocks, 88 regs | Q8_0 pair 2×17408×5120, 189 MB | 226.3 | 838 |
| 124160 blocks, 80 regs | LM head 248320×5120, 1.35 GB | 1564 | 864 |

Q8_0 is not an `mmvq_has_multi` type, so at 5 columns it runs the generic per-(column,row) loop: for each column j and
row i, `vec_dot_q8_0_q8_1()` (`ggml/src/ggml-cuda/vecdotq.cuh` ~851) reloads the weight ints with **16-bit loads**
(`get_int_b2`, block_q8_0 is 34 bytes: half d + 32 int8, so `qs` is only 2-byte aligned), VDR_Q8_0_Q8_1_MMVQ ints per
thread per iteration. ~1.5 s of the 7.5 s MMVQ time is Q8_0; the small-K/small-grid launches lose the most.

## Hypothesis
Per iteration each thread issues 2×VDR 16-bit weight loads per row (and possibly again per column if the compiler does
not CSE across j), plus the per-column y loads. Loading the weight slice of each row ONCE per iteration with fewer,
wider loads (e.g. two 32-bit loads + `__funnelshift_r`/byte_perm to rebuild the 2-byte-misaligned ints, or an aligned
int2/int4 load covering the slice), then dotting it against all 5 columns, cuts load instructions and raises bytes in
flight. Result must be **bitwise identical**: the same int32 `sumi` values (integer sums are exact) and the same float
expression per (row, column, block), accumulated into `tmp[j][i]` in the same order over kbx, with the same
thread→(kbx, kqs) mapping (keep vdr, nwarps, rows per block).
