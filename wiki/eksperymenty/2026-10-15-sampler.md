# 2026-10-15: sampler bez wolnych ścieżek (0065–0069)

**Web UI, budżet myślenia, `logit_bias` i gramatyka narzędzi omp po cichu włączały pełne sortowanie 128k/248k kandydatów; po łatkach LFM ~255 → ~293 t/s i Qwen MTP +6–8% w tych ścieżkach, przy tych samych tokenach.**

Serwer (świeży, `samp_ab.py`, seed 11, T=0.8, 800 tokenów), slow → fast:

| przypadek | LFM | Qwen MTP |
|---|---|---|
| zwykły | 293.2 → 293.3 | 104.6 → 104.6 |
| `reasoning_control` (web UI) | 256.9 → 292.9 | 101.6 → 109.5 |
| budżet myślenia 2048 (UI Low/Medium/High) | 256.9 → 292.9 | 99.3 → 107.0 |
| narzędzia (omp, leniwa gramatyka) | 254.2 → 294.3 | 104.8 → 113.2 |
| `logit_bias` | 257.1 → 292.6 | 98.9 → 105.4 |

Weryfikacja: harness CPU 312k wektorów, 0 różnic; md5 tekstu i wywołań narzędzi fast == slow we wszystkich 5 przypadkach (narzędzia LFM 2 × 2 przebiegi).

`run-llm.sh` ustawia `LLAMA_SERVER_REASONING_CONTROL=0` (łatka 0065); od 0066–0069 web UI z budżetem myślenia i narzędzia omp idą szybką ścieżką także bez tego.
